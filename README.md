# ГК «Ремедиум» — стратегия развития

Интерактивная презентация стратегии развития ГК «Ремедиум»: от отдельных активов к связанной платформе данных, решений и их реализации.

## Открыть презентацию

После включения GitHub Pages презентация доступна по адресу:

<https://elena-lvova.github.io/remedium-strategy-presentation/>

## Содержание

- связанный контур клиентской ценности;
- шесть направлений развития;
- интерактивная карта связей между направлениями;
- детализация текущих активов и вариантов развития;
- пакетные решения и предложения для государственного сегмента;
- живая стратегическая доска.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Публикация

GitHub Pages публикуется автоматически из ветки `main` через GitHub Actions.
